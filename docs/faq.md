# 常见问题

**旋钮还能用吗？** 能。主机音量照常增减（实测 50% → 48%），只切断了往屏幕画条子的那条路。

**会不会丢配置？** 不会。「一键修复」在你自己这块键盘的固件上打补丁，只改 22 字节，
profile、灯效、键位、厂商 app 的设置全保留。

**刷坏了怎么办？** 工具写入前一定先备份整片 flash，写完读回逐字节校验，不一致就报错。
真出问题就用备份文件在「固件」页刷回去。

**要装驱动吗？** 不用。工具直接走 HID，Windows 自带驱动就够。

**工具改了固件的哪些地方？** 只有应用区里那两个补丁位置，bootloader、profile、键位表都不碰。

**为什么屏幕上的音量是错的？** 厂商 app 把系统音量乘 100 下发，主控原样转发、零限幅，
屏幕照着画 —— 键盘并不知道真实音量。[补丁说明](/patches)

**我不想用这个工具？** 官方 app 没有"不画音量条"这个选项，不改固件就改不掉。
