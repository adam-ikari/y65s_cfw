YD-Y65S 屏幕音量条修复工具

键盘屏幕上那条音量条，和你系统里的真实音量对不上（有时候还固定显示 100%）—— 这是厂商固件的一个转发逻辑问题，不是硬件坏了。下面的工具一键修好它， 而且只改固件里的两个字节块，你的配置、灯效、键位都不动。

下载

Windows 用户。两个版本功能一样，命令行版免安装。

下载 y65s.exe（免安装） 下载 fix-volume.bat 桌面应用（安装包） 出厂固件 + 修复

仓库：github.com/adam-ikari/y65s_cfw

怎么修（推荐：命令行版）

  1. 把 y65s.exe 和 fix-volume.bat 放在同一个文件夹。
  2. 接上键盘的 USB 线，运行期间不要拔线。
  3. 双击 fix-volume.bat（或者在命令行里敲 y65s.exe fix-volume）。
  4. 等它跑完，最后一行是 「读回逐字节一致 ✓」 就成了。

工具做的事，和它做事的顺序都是固定的、可以复核的： 

读出整片 flash（64 KiB）→ 存一份备份 → 打两条字节级补丁
→ 擦除应用区 → 写入 → 读回逐字节校验 → 重启

为什么屏幕上的音量是错的

厂商 app 用 Windows 的 IAudioEndpointVolume 读系统音量（0.0~1.0）， 乘以 100 下发给键盘；键盘主控（8051）原样转发、零限幅， 屏幕模块照着画。键盘自己并不知道真实音量，于是那条条子和系统音量对不上， 甚至在 app 没运行时停在 100%。

音量旋钮在主控上（0x2812 采 P4.2/P0.7 正交解码）： 它同时做两件事——把 HID consumer 用量 0xE9/0xEA 发给主机（系统音量照常增减）， 再把状态字节 0x81/0x82 通知屏幕模块（屏幕据此画条子）。

改了什么

两条补丁，一共 22 个字节，都在出厂固件里被逐字节核对过（expect 对不上就拒绝写入）：

补丁地址作用
no-volume-send 0x5557（8 B） 去掉主控把 profile 音量字段（偏移 0x31）拷进「发给屏幕的设置包」那一次拷贝。 屏幕拿不到音量，也就没有那条不对的音量条；不塞哨兵值、不塞假值。
no-volume-ods 0x059C（40 B） 旋钮分支不再写 xdata[0x0EE4]=0x81/0x82，也不发那条 cmd 0x15 通知； 但 RAM 0x57 的 0xE9/0xEA 照写 —— 主机侧音量照常加减。

出厂固件 + 修复 ＝ firmware/YD-Y65S_full.bin + 上面两条， md5 4322b1c5b5d18ecd3644241637b1630f，与出厂 dump 的差异恰好 22 字节。

常见问题

旋钮还能用吗？

能。主机侧的系统音量调节完全不受影响 —— 实测转动旋钮，主机音量从 50% 正常变到 48%。 只是屏幕不再跟着画那条条子了。

会不会把我自己的配置弄丢？

不会。命令行版的一键流程是在你自己这块键盘的固件上打补丁再写回， profile（灯效、模式、音量字段、时钟）、键位表、厂商 app 的设置全部原样保留。
想彻底重置成出厂固件（顺带修好音量条）的话，用上面的「出厂固件 + 修复」镜像， 用 y65s.exe flash YD-Y65S_factory_volume_fixed.bin 刷 —— 那个会把 profile 换回出厂值。

刷坏了怎么办？

工具在动手之前一定会先把整片 flash 存成备份文件（当前目录下的 YD-Y65S_backup_*.bin），刷写失败也能用 y65s.exe flash <备份> 写回去。工具本身不会碰 bootloader 区 （0xF000–0xFFFF），只有应用区会被擦写。

这是怎么验证的？

每一次写入之后都会把整片 flash 读回来，与目标镜像逐字节比较 （bootloader 自己管的 0xEFFB–0xEFFF 除外）。 不一致就报错，不会假装成功。

技术细节

整个项目（固件逆向、补丁表、ISP 实现、工具源码）都在 github.com/adam-ikari/y65s_cfw， 补丁表在 tool/crates/core/src/patch.rs，ISP 实现（Sinowealth 0x55/0x52/0x45/0x57/0x77/0x5a）在 tool/crates/core/src/isp.rs。 写入顺序（擦除 → 写页 → enable → 重启）有单元测试盯着， 因为顺序错了键盘会开不了机。

固件里的绝大多数字节仍然是厂商原厂固件；这个项目只做可审计的字节级补丁， 每条补丁都带「期望的原字节」，对不上就拒绝写入。 工具按「先备份、后写入、再校验」的方式工作。

硬件型号 SINO WEALTH YD-Y65S（USB 258A:019D，Sinowealth SH68F90/A）。
